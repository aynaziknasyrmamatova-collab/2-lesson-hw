В то время как modelSerializer0 это типо умный сериализатор который сам подстравивается.
отличаются они друг от друга теи что сериализер ты настраиваешь вручную, а моделсериализер это готовый шаблон который просто копирует структуру твоей таблицы
2. миксины нужны для того чтобы не писать один и тот же код по сто раз
3. чтобы пользователь не мог просматривать чужие бронирования можно просто через permissions

post-созать, чтобы создать что- то новое, например броонирование

patch- изменить частично, нужен только для частичного изменения щзаписи
delete- удалить, нужен просто чтобы стереть запись из базы данных
