***********************************************************************************
При использовании Windows 7
***********************************************************************************

Можно использовать программное обеспечение, которое содержится на данном 
компакт-диске с Windows 7.

Для получения инструкций по установке каждого пакета программ см. руководство, 
поставляемое с принтером.


Предупреждения
==============
Если драйвер принтера используется с Windows 7, обратите внимание на следующие 
предупреждения и ограничения.

* В зависимости от используемой модели принтера, возможно, не удастся правильно 
  установить драйвер принтера в режиме Windows XP.
* Следующее программное обеспечение, содержащееся на компакт-диске, не 
  pаботает Windows 7.
  - драйвер принтера UFRII LT XPS.
  - WIA Network ScanGear
