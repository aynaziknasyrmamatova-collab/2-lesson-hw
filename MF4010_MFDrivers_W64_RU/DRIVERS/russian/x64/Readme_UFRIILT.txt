  Canon Driver Configuration Tool. Для получения более подробной
  информации об этой утилите обратитесь к документу "Canon Driver
  Configuration Tool User's Guide".


Системные требования
====================
Драйвер принтера Canon UFR II может использоваться в
перечисленных ниже системах.

* Операционные системы
  Microsoft Windows XP Professional x64 Edition
  Microsoft Windows Server 2003, Enterprise x64 Edition
  Microsoft Windows Server 2003, Standard x64 Edition
  Microsoft Windows Vista x64 Edition

* Компьютер
  Любой компьютер, на котором успешно функционирует
  указанное выше системное программное обеспечение.
  Кроме того, необходим хотя бы один из следующих портов вывода:

 - сетевой интерфейс;
 - порт USB.

  Для достижения наилучшей производительности печати
  рекомендуется использовать сетевой интерфейс.


Установка драйвера принтера
===========================
Для использования данного драйвера принтера с прикладными
программами, работающими в системах Microsoft Windows
XP/Server 2003/Vista x64 Edition необходимо выполнить
следующую процедуру установки.

Примечание
----------
* Если вы осуществите вход в систему Windows 2000/XP/Server
  2003/Vista x64 Edition в качестве опытного пользователя (Power User)
  и запустите программу установки, установка может не завершиться
  корректно. В этом случае осуществите вход в систему в качестве
  администратора и повторите установку.
* Если при использовании программы установки появляется сообщение,
  предлагающее перезагрузить компьютер, обязательно выполните
  перезагрузку компьютера. Если не выполнить перезагрузку компьютера,
  имеющиеся драйверы могут работать неправильно.

Важно
-----
При использовании устройств iR1018/1022/1023, MF4100, MF4660,
MF4690 и MF6500 процедура установки отличается от описанной в
данном файле. Сведения по установке см. в руководстве
по соответствующему принтеру.

Порядок установки с помощью программы установки
1. Дважды щелкните значок Setup.exe в папке \UFRII\russian\x64,
   чтобы запустить процедуру установки.
2. Нажмите кнопку "Далее" в первом диалоговом окне мастера установки
   драйвера принтера и затем следуйте инструкциям на экране.
3. Выберите "Вручную настроить порт для установки",
   затем нажмите кнопку "Далее".
4. При отображении диалогового окна выбора элементов для
   установки выберите драйвер принтера UFR II и нажмите кнопку "Далее".
5. При отображении диалогового окна выбора того, как должна
   производиться установка, выберите "Добавить принтеры" или "Добавить
   принтеры и обновить существующие драйверы" и нажмите кнопку "Далее".
6. Выберите драйвер, который требуется установить, из списка принтеров
   и нажмите кнопку "Добавить".
7. Убедитесь, что драйвер, который требуется установить, выбран в
   диалоговом окне "Драйвер принтера - мастер установки".
   Затем нажмите кнопку "Далее".
8. Выберите порт из раскрывающегося меню или нажмите кнопку
   "Добавить порт". Затем нажмите кнопку "Далее".
9. В следующем диалоговом окне проверьте параметры установки,
   затем нажмите кнопку "Запуск".
10.По окончании копирования файлов нажмите кнопку "Next".
11.Нажмите кнопку "Выход" для завершения программы установки.

Теперь принтер готов к печати из любых приложений Windows.

Примечание:
*  Можно добавить новый драйвер, не затрагивая уже имеющийся,
   если в действии 6 выбрать "Добавить принтеры". Если выбрано
   "Добавить принтеры и обновить существующие драйверы", все
   существующие драйверы автоматически обновляются при добавлении
   нового драйвера.
*  При использовании общего принтера в системе с сервером печати
    (метод "Указание и печать") необходимо установить на сервере службу
   информационной помощи драйвера Canon на сервере для автоматической
   настройки конфигурации принтера или использования функции "Учет заданий".
*  При использовании операционной системы, оснащенной брандмауэром
   Windows, в процессе установки отображается сообщение с запросом на
   изменение настроек брандмауэра Windows.
   - При выборе ответа "Да" брандмауэр Windows будет настроен на разрешение
     соединения для службы информационной помощи драйвера Canon,
     позволяя автоматически настраивать конфигурацию принтера и
     использовать функцию "Учет заданий".
   - При выборе ответа "Нет" использование службы информационной помощи
     драйвера Canon невозможно.

Порядок установки с помощью мастера добавления принтера
1. В меню "Пуск" выберите "Настройка", затем "Принтеры".
   - При использовании Windows XP Professional/Server 2003 в меню
     "Пуск" выберите "Принтеры и факсы".
   - При использовании Windows Vista в меню "Пуск" выберите
     "Панель управления", а затем "Принтеры".
2. В папке "Принтеры" дважды щелкните значок "Установка принтера"
   (Windows XP/Server 2003) или щелкните пункт "Установка принтера"
   (Windows Vista) для запуска мастера установки принтера.
3. Подтвердите запуск мастера, а затем нажмите кнопку "Далее".
4. Для продолжения процесса установки следуйте инструкциям на экране.
5. Нажмите кнопку "Установить с диска".
6. Нажмите кнопку "Обзор" для выбора следующей папки, затем
   нажмите кнопку "ОК".
   - Windows XP/Server 2003/Vista: \UFRII\russian\x64\DRIVER
   
7. Выберите модель принтера из списка и нажмите кнопку "Далее".
8. Для продолжения следуйте инструкциям на экране,
    затем нажмите кнопку "Готово".

Теперь принтер готов к печати из любых приложений Windows.

Порядок установки с использованием соединения USB
Можно выполнять печать в среде USB. Установите драйвер принтера,
подключенного через USB.

1. Дважды щелкните значок Setup.exe в папке \UFRII\russian\x64,
   чтобы запустить процедуру установки.
2. Нажмите кнопку "Далее" в первом диалоговом окне мастера
   установки драйвера принтера и затем следуйте инструкциям на экране.
3. Выберите "Установить с соединением по USB" и нажмите кнопку "Далее".
4. Нажмите кнопку "Да" в окне сообщения с запросом о запуске установки.
5. При появлении диалогового окна с запросом подсоедините
   принтер к разъему USB и включите его.
6. По окончании копирования файлов нажмите кнопку "Next".
7. Нажмите кнопку "Выход" для завершения программы установки.


Доступ к диалоговому окну "Свойства"
====================================
Диалоговое окно "Свойства" содержит несколько вкладок, позволяющих
настраивать принтер и управлять им.  Для получения доступа к
диалоговому окну "Свойства" используйте описанные ниже процедуры.

 Порядок доступа с рабочего стола
 1. В меню "Пуск" выберите "Настройка", затем "Принтеры".
   - При использовании Windows XP Professional/Server 2003 в меню
      "Пуск" выберите "Принтеры и факсы".
   - При использовании Windows Vista в меню "Пуск" выберите
     "Панель управления", а затем "Принтеры".
 2. Щелкните правой кнопкой мыши значок необходимого принтера в
    папке "Принтеры" и выберите "Свойства" для открытия диалогового
    окна "Свойства принтера", либо щелкните "Настройка печати" для
    открытия диалогового окна "Свойства документа".

 Порядок доступа из приложения
 1. Выберите команду "Печать" для отображения диалогового окна "Печать".
 2. Выберите имя необходимого принтера из раскрывающегося
    списка и нажмите кнопку "Свойства".


Доступ к справочной информации
==============================
В диалоговом окне "Свойства" можно нажать кнопку
"Справка" для отображения информации о драйвере принтера UFR II. 


Предостережения, ограничения и запреты
======================================
1. При использовании функции разбора по копиям в приложении и варианта
   "Переплет внакидку" для функции "Печать брошюры" вся бумага будет
   отсортирована и сшита внакидку. При использовании варианта
   "Переплет внакидку" для функции "Печать брошюры" отключайте
   в приложении функцию разбора по копиям.

2. При создании пользовательского размера бумаги в диалоговом
   окне "Свойства сервера печати" в Windows XP/Server 2003/Vista x64
   Edition указывайте следующую
   ширину полей:
   - 0,50 см (0,20 дюйма) или более.

3. При установке с помощью функции "Установка принтера" из папки
   "Принтеры" может появиться сообщение о невозможности найти цифровую
   подпись. При появлении этого сообщения продолжайте установку.
   Установка принтера пройдет корректно.

4. Если при печати документа необходимо использовать вариант
   "Страница с ярлыками", то при выборе значения "Тип бумаги" для параметра
   "Выбор по" на вкладке "Источник бумаги" установите для параметра
   "Выбор бумаги" значение "Одна и та же бумага для всех страниц".
   При указании нескольких различных типов бумаги для печати каждой
   страницы документа печать на странице с ярлыками может быть выполнена 
   некорректно.

5. При печати в приложении QuarkXPress документ может быть не напечатан,
   а на выходе будут пустые страницы. В этом случае выберите значение
   "Выключено" для параметра "Буферизация на узле" на
   вкладке "Параметры устройства".

6. При печати документа с прикрепленными объектами EPS
   распечатка может быть некорректной.
    
7. При использовании среды удаленного рабочего стола или при совместном
   использовании Windows несколькими пользователями для автоматической
   настройки конфигурации принтера необходимо использовать
   TCP/IP в качестве сетевого протокола.

8. Если при вставке листов в документ случайно указать в качестве их
   источника лоток, содержащий бумагу с ярлыками, настройка автоматически
   изменится на лоток с обычной бумагой.

9. Если при использовании приложения Adobe Illustrator 9.0 или более поздней
   версии не выбрать функцию "Печать точечного рисунка", то либо для печати
   может потребоваться большее количество времени, либо тонкие линии или
   символы могут оказаться размытыми. При возникновении такой проблемы
   выберите функцию "Печать точечного рисунка".

10.Для печати документа на компьютере с низким быстродействием может
   потребоваться большее количество времени.

11.Если для параметра "Буферизация на узле" на вкладке "Параметры
   устройства" выбрано значение "Выключено", укажите кассету в
   качестве источника бумаги для печати брошюры.

12.При выборе значения "Прозрачная пленка" или "Ярлык" для параметра
   "Тип бумаги" на вкладке "Источник бумаги" может появиться сообщение
   о том, что печать документа невозможна и необходимо изменить тип бумаги.
   В случае появления этого сообщения можно выполнить печать документа,
   если отменить выбор параметра "Сместить" на листе "Окончательная обработка".

13.Иногда при установке драйвера принтера зарегистрированная в принтере
   информация о пользовательском типе бумаги может извлекаться неправильно.
   В этом случае следует повторно получить правильную информацию, нажав
   кнопку "Опрос состояния устройства" в окне "Параметры устройства"
   или кнопку "Получить сведения о бумаге" в диалоговом окне "Параметры
   бумаги", отображаемом при нажатии кнопки "Настройки" в окне
   "Источник бумаги".

14.При использовании в имени принтера символа "@" этот принтер
   не распознается операционной системой, поскольку такое имя принтера
   является недопустимым, в результате чего эксплуатация и настройка
   принтера, а также печать на нем становятся невозможны.

15.При печати из приложения двухстороннего документа с нечетным
   числом страниц приложение может автоматически вставить пустую
   страницу для получения четного числа страниц. В этом случае вставленная
   приложением пустая страница учитывается так же, как и напечатанная.

16.Определение пользовательского размера бумаги: для изменения
   параметра "Пользов. размер бумаги" в области "Параметры страницы"
   диалогового окна настроек печати в драйвере принтера необходимо
   обладать правами администратора.

17.Если выполнить вход в систему с помощью учетной записи
   администратора, отличной от той, которая использовалась для
   установки программного обеспечения, свойства драйвера будут
   недоступны даже при наличии прав администратора. Для доступа к
   свойствам драйвера выберите [Запуск от имени администратора].

18.В некоторых приложениях для толщины линии можно задать
   значение менее 1 пт, однако действительная толщина линии при
   печати может быть равна 1 пт.

19.При печати документа с разрешением 1200 dpi, установленным
   в приложении, ступенчатые края изображений могут быть заметнее,
   чем при печати с разрешением 600 dpi.
