📚 Список книг (ListView)

💡 Как работает ListView:
1. В views.py мы указали model = Books.
2. Django сам выполнил: Books.objects.all().
3. И передал все книги в этот шаблон под именем books.
4. Здесь мы просто перебираем их циклом {% for book in books %}!
{% if books %} {% for book in books %}

{{ book.title }}

{% if book.description %}

{{ book.description|truncatewords:25 }}

{% endif %}

💰 Цена: {{ book.price }} сом
