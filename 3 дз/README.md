# Task API

REST API на Django REST Framework для создания и просмотра задач.

## Запуск

```powershell
py -m pip install -r requirements.txt
py manage.py migrate
py manage.py createsuperuser
py manage.py runserver
```

API доступно по адресу `http://127.0.0.1:8000/api/tasks/`.
Админка доступна по адресу `http://127.0.0.1:8000/admin/`; после входа в ней можно просматривать и редактировать задачи.

`GET /api/tasks/` возвращает список, `POST /api/tasks/` создает задачу. Для одной задачи используются маршруты `/api/tasks/<pk>/`:

- `GET` получает задачу;
- `PUT` полностью обновляет задачу;
- `PATCH` обновляет только переданные поля;
- `DELETE` удаляет задачу.

Пример JSON для создания или полного обновления:

```json
{
  "title": "Подготовить отчет",
  "description": "Квартальные результаты",
  "status": "in_progress",
  "priority": 4,
  "due_date": "2027-01-15T12:00:00Z"
}
```

Поля `description`, `status`, `priority` и `due_date` необязательны. `id`, `created_at` и `updated_at` формируются сервером и доступны только для чтения.

Успешное чтение и обновление возвращает `200`, создание — `201`, удаление — `204`. Ошибочные данные дают `400`, несуществующий `pk` — `404`. Код `300` не используется: эти операции не перенаправляют клиента. Код `500` означает непредвиденный сбой сервера, а не ошибку введенных данных.

Для проверки, включая ответы с ошибками, выполните:

```powershell
py manage.py test tasks
```
